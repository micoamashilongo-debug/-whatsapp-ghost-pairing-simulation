# WhatsApp Ghost Pairing Attack – Interactive Simulation

This project is an **interactive browser-based simulation** that demonstrates how the **WhatsApp Ghost Pairing scam** works.  
It is designed purely for **education and awareness**, helping users understand how social engineering tricks people into linking their WhatsApp account to an attacker’s device.

🚫 This project does **not** perform real pairing, hacking, or login operations.  
🧠 It is a **visual demo only** and contains **no backend or real network connections**.

---

## 🎯 Purpose

- Cybersecurity awareness
- Phishing and social engineering education
- Classroom and workshop demonstrations
- Safe practice environment without real-world risk

---

## 🧩 What this simulation shows

- Fake chat message containing a malicious link  
- Phishing landing page pretending to be identity verification  
- Attacker dashboard visualization  
- Fake “code capture” and “session clone” messages  
- Step-by-step psychological manipulation flow

This helps users recognize:
- why pairing codes must never be shared  
- how attackers exploit trust
- common red flags in fraudulent webpages

---

## 🚀 How to use

1. Download or clone this repository
2. Open the HTML file in any browser
3. Click the phishing link inside the simulated chat
4. Enter any random 8-character code
5. Watch how the fake attacker dashboard updates

No servers, no APIs, no installations required 👍
